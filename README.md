# 継続力ダッシュボード

毎日の発信や作業を無理なく続けるためのシンプルな継続管理Webアプリです。
Firebaseを使用してデータをクラウド保存し、複数端末で同期できます。

## 🌟 主な機能

- **今日の作業管理**: タスク・予定時間・モードの記録と完了チェック
- **月間進捗ダッシュボード**: 活動日数・時間・投稿数の進捗可視化
- **デイリーログ**: 月間実績の一覧表示・編集
- **ネタストック & 振り返り**: アイデア保存と1日の振り返り
- **データ連携**: JSONエクスポート/インポート、PWA対応

## 🚀 使い方

1. ユーザーネームと6桁のパスワードを入力してログイン（未登録の場合は自動作成）。
2. 作業内容を入力し、終了時に **「💾 変更を保存する」** を押してクラウド保存。
